# CipherForge

Мобильное приложение для шифрования и дешифрования данных с поддержкой классических
и современных криптографических алгоритмов. Позволяет шифровать текст, согласовывать
общий ключ с собеседником (ECDH) и хранить защищённые заметки под мастер-паролем.
Приложение работает полностью офлайн — все данные обрабатываются на устройстве,
ничего не передаётся на сервер.

## Возможности

- **Шифры:** Цезарь, Виженер, AES-256-GCM
- **RSA** — гибридное шифрование (AES-ключ шифруется публичным RSA-ключом получателя)
- **ECDH** — обмен ключами: генерируешь свой ключ, вставляешь публичный ключ собеседника, получаете общий AES-ключ для переписки
- **Защищённое хранилище** заметок/паролей — ключ шифрования выводится из мастер-пароля (PBKDF2), данные пока хранятся в памяти на время сессии

## Стек

- Kotlin
- Android
- Jetpack Compose (MVVM — логика вынесена в ViewModel)
- `javax.crypto` — AES, RSA, ECDH, PBKDF2

## План развития

- персистентность хранилища (Room/SQLite) — сейчас заметки живут только в памяти
- ChaCha20 как альтернатива AES
- обмен публичным ключом через QR-код
- экспорт и передача зашифрованных файлов (сохранение на устройство, share-интент)
- юнит- и UI-тесты
- бенчмарк производительности алгоритмов
- полировка интерфейса

## Запуск

Открыть проект в Android Studio и выполнить Gradle Sync.
