# CipherForge
CipherForge - клиентское Android-приложение на Kotlin для шифрования и дешифрования данных. Поддержка классических и современных криптографических алгоритмов, обмен ключами через QR-код, экспорт зашифрованных файлов, защищённое локальное хранилище заметок. Работает полностью офлайн.
# Возможности (планируются)
- шифрование и дешифрование текста;
- классические шифры (Цезарь, Виженер) — обучающий режим;
- симметричное шифрование (AES-256, ChaCha20);
- асимметричное шифрование и обмен ключами (RSA, ECC);
- сохранение и передача зашифрованных файлов
# Стек
- Kotlin
- Android
- Jetpack Compose
# План развития
- ядро шифрования: классические шифры + AES-256;
- асимметричное шифрование (RSA) и обмен ключами (ECC/ECDH);
- обмен публичным ключом через QR-код;
- защищённое хранилище заметок/паролей (Argon2/PBKDF2);
- экспорт и передача зашифрованных файлов (сохранение, share-интент);
- юнит- и UI-тесты;
- бенчмарк производительности алгоритмов;
- полировка интерфейса.
# Запуск
Открыть проект в Android Studio и выполнить Gradle Sync.
